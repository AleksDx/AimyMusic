# AimyMusic

A music streaming web app with glassmorphic design, AI-curated feeds, an animated aura player, playlists with drag-and-drop, and a Wrapped-style year-in-review.

## Tech Stack
- React + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion (animations)
- Howler.js (audio engine)
- Zustand (state management)
- Supabase (auth + database)
- @dnd-kit (drag-and-drop)
